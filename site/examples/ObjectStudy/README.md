# ObjectStudy

Original AI-assisted teaching starter for Intro Java. This is a small mechanism example, not a completed assignment.

## Open
Extract the ZIP. Keep `ObjectStudy.pde` inside its matching `ObjectStudy` folder. Open that file in Processing Java mode and run it.

No external libraries or data assets are required. Controls, if used, are identified in the code. ModeStudy: click to start, release R to reset. InputStudy: hold a key to move, release R to reset.

## Verification
Source and package structure were checked during site assembly. This sketch has not yet been executed in the classroom Processing environment. Record the tested Processing version here after running it.
