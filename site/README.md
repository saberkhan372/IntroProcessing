# Intro Java site source

Open index.html locally, or see the repository README for editing, verification, and GitHub Pages instructions.

Notes save on this device when storage is available. Use Notebook → Backup JSON to move or protect your work. The source includes no student submissions. All ten Processing starters compiled and passed startup smoke tests in Processing 4.3.4. Browser-rendered appearance and interactive sketch behavior remain unverified; teacher review is required before adopting the proposed lessons as assignments.

## Unit 1 daily slides

Open #unit1 for six 75-minute sessions, each with ten slides, a workbook, an outline, and Markdown download. Dates are suggested, not assigned. Edit `unit-one.js` to change daily content. Present uses arrow keys; Escape returns to Study.
